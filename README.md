# Magic Survival Clone

## Description
A survival game inspired by Magic Survival created with Python and Pygame.

## Features
- Infinite map
- Enemy spawning system
- Auto shooting
- HP system
- Score and highscore
- Increasing difficulty over time
- Game over screen

## Technologies
- Python
- Pygame
- JSON

## How to Run
1. Install pygame:
pip install pygame

2. Run the game:
python main.py
